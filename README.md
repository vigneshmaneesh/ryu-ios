# Ryu iOS

Native iOS 27 proof of concept using Ryujinx's ARM64 code emitter and external StikDebug activation.

This first milestone tests native code generation and JIT execution. It does not load or run Switch games yet.

See [ios/README.md](ios/README.md) for build and device-testing instructions. GitHub Actions builds a re-signable IPA on a standard macOS runner in this public repository.
